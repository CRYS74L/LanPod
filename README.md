# LanPod

> 你的局域网设备助手

一个面向 Windows 11 的原生桌面工具，通过小米路由器管理接口查看局域网设备。

## 功能

- 实时查看设备在线状态、上传/下载速度和累计流量；
- 从工具首次运行起持续记录设备上线与离线历史；
- 历史日期优先使用“今天、昨天、前天”，默认展示最近三段会话；三段以内全部显示，每次展开最多再展示十五段，全部展开后可平滑收起回到三段；
- 在线、离线设备列表分别显示最近上线、离线发生在多久之前，悬停可查看准确时间；
- 连接指示灯使用半透明外圈和实心内圈；正常连接时每秒完成一次平滑呼吸，连接异常时停止呼吸；
- 根据路由器设备名识别手机、电脑、空调、灯、插座、音箱、路由器等设备类型；
- 自定义设备名称、类型和图标；
- 设备名称、类型、图标与上下线提醒选项修改后自动保存；
- 为指定设备开启上线、离线 Windows 系统通知，并可设置通知免打扰时段；
- 可选在 IPv6 连接类型不是 Native 时发送 Windows 系统通知；
- 查看路由器 IPv4、IPv6 上网信息；
- 查看 Mesh 网络中主路由与各节点分别连接的设备数量；
- 在浅色、深色与跟随系统三种主题间即时切换；
- 支持简体中文、繁體中文、日本語和 English，桌面设置中的界面语言会同步应用到局域网网页；
- 在应用内重启路由器，并持续显示重启与恢复进度；
- 关闭窗口后继续在系统托盘监控；
- 可选创建当前用户的 Windows 登录计划任务，在托盘中静默启动；
- 防止重复运行，再次打开程序时会直接唤醒已有窗口；
- 使用云母背景、统一圆角控件、轻量动效、细滚动条和圆角托盘菜单。
- 支持用鼠标侧键在设备、路由器和设置界面之间前进与返回。

应用已在小米路由器 AX3000T（RD03，固件 1.0.98）上完成真实接口联调。路由器请求固定绕过系统代理并直连局域网地址，不会改变 Codex、浏览器或其他应用的代理配置。

## 使用

1. 将 Windows x64 便携包解压到可写文件夹，打开其中的 `LanPod.exe`。首次启动会将随 EXE 提供的运行依赖展开到 `Data\Runtime`，后续启动直接复用，无需另外安装 .NET 或 Windows App SDK。
2. 首次运行时在“设置”中输入路由器地址与管理员密码。
3. 在左侧选择设备，即可查看实时网速、累计用量、连接信息和上下线历史。
4. 在“设备设置”中修改显示名称、类型和图标，并为指定设备开启上线或离线通知；修改后立即生效。
5. 设置页中的路由器地址、管理员密码、通知免打扰时段、IPv6 提醒、开机自启、颜色主题与界面语言均会在修改后立即应用。界面语言默认为简体中文，已打开的局域网网页会自动同步语言。
6. 点击右上角“路由器”查看 IPv4/IPv6 与 Mesh 节点信息，或在确认后重启路由器。
7. 在“设置”中可选择是否随 Windows 登录自动启动；从登录计划任务启动时只显示托盘图标，主动双击 EXE 时正常打开主界面。
8. 关闭窗口后，应用默认继续在系统托盘运行；右键托盘图标可打开主界面或退出应用。

从“局域网设备助手”升级后，Windows 中的新通知使用 LanPod 名称与图标，并自动沿用旧通知的开关偏好。通知中心保留的旧通知仍归属原来的发送方。

启动后，软件目录中只有 `LanPod.exe` 和 `Data` 文件夹。设置、设备历史、窗口位置、路由器密码、日志及展开的运行依赖均位于 `Data`。移动或备份时将这两项一起复制。升级时先退出程序，替换 `LanPod.exe` 并保留 `Data`。首次从旧版升级时，程序自动导入当前 Windows 用户的旧设置、设备历史和已保存密码。

程序自动创建当前用户的开始菜单快捷方式及 Windows 通知登记。移动目录后启动一次，程序会更新通知点击路径和已启用的自启动任务。首次使用局域网访问、升级或移动目录后，Windows 可能要求重新授权应用的防火墙规则。

软件持续读取路由器，只在获得新的有效统计时更新网速和更新时间，无需手动设置刷新频率。图表按自动识别的采样周期等间隔排列数据，缓冲约一个采样周期以连续滚动；网速值保留路由器观测结果。横坐标使用估算的采样时间，原始接收时间独立保留；缺失批次不会补造数值。

> 路由器本地接口不提供安装前的完整上下线历史，因此历史记录从本工具第一次观察到设备时开始积累；已在线设备的本次上线时间会根据路由器返回的在线时长自动回推。

## 隐私与凭据

路由器管理员密码使用 AES-GCM 加密保存在 `Data` 中，解密密钥也随该文件夹保存，因此可以跨电脑使用。持有完整 `Data` 文件夹的人能够读取已保存密码，请将它作为私人资料保管。分享便携程序时只分发原始压缩包，或先移除副本中的 `Data`。

## 手机、平板与局域网网页

1. 在电脑端设置中开启“允许局域网设备访问”。
2. 手机或平板连接同一局域网，扫描二维码，或打开旁边的链接。
3. 直接查看设备状态、连接信息、网速、流量曲线、上下线历史及路由器 IPv4/IPv6、Mesh 信息。

无需账号、访问码、证书、域名、云服务或额外 App；端口自动选择，被占用时自动避让。网页支持手机竖屏、横屏及平板，所有资源随软件打包，运行不需要访问外部网站。流量图与桌面端一致保留最近 10 分钟有效采样，可切换 1 / 5 / 10 分钟并点选查看数值；上下线历史分页读取全部已保存会话，包含持续时长。设备详情同时显示连接频段、IP/MAC、累计量与日期范围、原始名称、自定义资料及 Windows 提醒状态。监控信息页可查看电脑端偏好与版本。

开启后，同一局域网内能连接电脑的设备均可只读访问这些信息；请只在信任的局域网中开启。电脑需保持运行，关闭窗口到托盘后仍可访问；关闭开关或退出软件后停止服务。没有网卡时仅本机可访问，网络或电脑 IP 变化后重新开启即可更新链接。首次开启时，软件自动检查 Windows 访问规则；需要配置时会弹出系统管理员授权，只需点击“是”。规则限定当前程序、实际网页端口及同一局域网，兼容 Windows 将家庭网络标为公用网络的情况；不会关闭防火墙，也不会修改 Clash。已正确配置时不会重复要求授权，取消授权会停止服务并关闭开关，之后可重新开启重试。移动程序位置或端口变化后可能需要重新授权。组织安全策略、第三方防火墙或访客网络隔离仍可能阻止连接，软件不能绕过这些限制。

手机推送功能已移除，网页没有通知权限申请、推送订阅或证书安装步骤。现有 Windows 系统通知及免打扰规则不变。旧版生成的本机加密网页配置不再读取，也不会自动删除；软件从未自动安装系统根证书，若用户曾手动在手机安装旧 CA，可以自行删除。
### 主屏幕图标与移动体验

网页图标完整保留原始图形与配色，并区分用途：浏览器 favicon 使用透明背景、无底板、等比撑满画布的原图；苹果主屏幕专用图标增加留白及白色不透明底板，输出为无透明通道 RGB 图标，提供 180 / 167 / 152 像素 Apple Touch Icon 和 192 / 512 像素主屏幕图标，母版为 1024 像素。图标使用完整方形背景，由系统裁切圆角；图形留白为视觉设计选择，不以截图中其他 App 的大小为标准。更新前已经添加到 iPhone/iPad 主屏幕的旧书签可能缓存旧图标，请删除旧书签后从 Safari 重新添加一次。无需安装证书或额外 App。

界面跟随系统深浅主题，尊重减少动态效果/透明度设置；手机使用分层导航，横屏与平板使用列表和详情分栏。所有页面继续只读。

## 本地构建

运行 `scripts\build.ps1` 构建，运行 `scripts\publish.ps1` 将完整运行依赖封装为单个 Release EXE，再运行 `scripts\package-portable.ps1` 生成便携 ZIP。脚本优先使用项目内 `.tools\dotnet` SDK，发布目录为 `dist\LanPod`。该目录应只包含 `LanPod.exe`；打包时不包含运行生成的 `Data`。

托盘原生模块和便携启动器使用 LLVM-MinGW 的 `clang++`（x86-64、C++20）构建。可将编译器加入 `PATH`，或用环境变量 `LAN_TRAY_CXX` 指定完整路径；资源编译器 `llvm-rc.exe` 应位于同一目录。MSBuild 自动调用 `scripts\build-native-tray.ps1`。发布脚本使用 Windows 自带的 `makecab.exe` 封装运行依赖，启动器通过 Windows Cabinet API 展开至程序目录内。运行软件不需要安装编译器。

应用图标由 `scripts\GenerateIcon.ps1` 生成，源文件输出到 `src\LanPod.App\Assets\AppIcon.ico`。

流量曲线采用 Apache ECharts 6.0.0 的平滑算法，平滑系数为 `0.50`。网页模块及桌面移植的来源、许可证和重新生成方式见 [ThirdParty/echarts](src/LanPod.App/ThirdParty/echarts/UPSTREAM.md)。
